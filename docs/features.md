# Features

- Task management
- Daily journal
- Productivity analytics
- Task tags and tag-based filtering
- CSV and JSON task export
- CSV task import with validation and duplicate detection
- Detailed analytics: tag and priority completion rates, deadlines, task age and insights
- Daily and weekly goals with progress tracking
- Task completion timestamps
- Completion streaks: current, longest and daily-goal streaks
- Task editing, detail view and reopening
- Input validation with clear CLI error messages
- Time tracking with timers, manual entries and summaries
- Recurring tasks (daily, weekly, monthly)
- Database backup, verification, restore and pruning
- Task dependencies with ready and blocked views
