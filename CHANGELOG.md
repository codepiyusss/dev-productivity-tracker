# Changelog

## Unreleased
- Add `today` command: overdue, due today and upcoming tasks, running timer, goal progress, streak, and how many tasks are ready or blocked.
- Add task dependencies: `depend add TASK BLOCKER`, `depend remove` and `depend list`. A task can wait for one or more others; circular chains are rejected.
- `list --ready` shows pending tasks nothing is blocking, and `list --blocked` shows tasks waiting on unfinished tasks. Blocked tasks are marked `BLOCKED by ...` in listings.
- `complete` refuses to finish a blocked task unless `--force` is given, and announces tasks that were freed up.
- `show` lists what a task waits for and what needs it; the detailed report and insights mention blocked tasks.
- Add a `task_dependencies` table (created automatically on existing databases); backups count and restore dependencies.
- Add database backup and restore: `backup create`, `list`, `verify`, `restore` and `prune`.
- Backups are consistent snapshots made with SQLite's backup API and are verified (integrity and foreign key checks) before they are kept.
- Restoring verifies the backup first, saves the current database as a `pre-restore` safety copy, and swaps the file in one step. Safety copies are never pruned.
- Add `backup create --keep N` for automatic pruning and `import --backup` to save a copy before importing.
- `import` now exits with code 1 when it fails.
- Fix: database and journal connections are now closed as soon as each operation finishes. They used to stay open until garbage collection, which on Windows blocked replacing or deleting the database file.
- Restore retries briefly and then reports a clear error if another program has the database file open.
- Add recurring tasks: `add --repeat daily|weekly|monthly`, and `edit --repeat` / `--no-repeat`.
- Completing a repeating task creates the next occurrence (same title, priority, category and tags) with the next due date.
- Repeating tasks require a due date; the schedule never leaves a pile of overdue copies after late completion.
- Add a `recurrence` column to tasks (added automatically to existing databases); repeat rules show in `list` and `show` and round-trip through CSV and JSON export and CSV import.
- Add time tracking: `timer start`, `stop`, `status`, `log`, `list`, `summary` and `delete`.
- Add a `time_entries` table (created automatically on existing databases); only one timer can run at a time.
- Completing a task stops its running timer; `show` displays time spent; the detailed report has a TIME TRACKING section.
- Add `export --include-time` to add a `time_spent_seconds` column.
- Add `edit`, `show` and `reopen` commands; `delete` now asks for confirmation (skip with `--yes`).
- Validate due dates (real YYYY-MM-DD dates only), task IDs, journal dates and counts with clear error messages.
- Fix: invalid due dates such as `31-12-2026` were silently accepted when adding or updating a task.
- Fix: `TaskManager.update_task` now rejects invalid priorities and empty titles.
- Show due dates and an overdue marker in task listings.
- Add global `--db PATH` option and usage examples to `--help`.
- Show friendly messages instead of tracebacks for database and file errors; commands now return meaningful exit codes.
- Add streak tracking: current streak (with an end-of-day grace period), longest streak, daily goal streak and active-day totals.
- Add `streak` command with `--days` and `--json`; streak status also shows after `complete`, in the detailed report and in insights.
- Fix `get_completion_streak` to use completion dates instead of creation dates.
- Add daily and weekly goals: `goal set`, `goal show` and `goal clear`, with progress bars.
- Show goal progress after `complete` and in the detailed report.
- Track when tasks are completed (`completed_at`), with a safe migration for existing databases. Tasks completed before this version have no timestamp and do not count toward goals.
- Add `completed_at` to CSV and JSON exports.
- Improve analytics: completion rate by priority, category and tag, due-soon and overdue lists, pending task age, weekday patterns and plain-language insights.
- Add `stats --detailed` and `stats --json`; reports now include the new sections.
- Overdue detection no longer crashes on invalid due dates.
- Add `import` command to load tasks from CSV with validation, line-numbered row errors, duplicate skipping and `--dry-run`.
- Add `export` command to save tasks as CSV or JSON, with status, priority, category and tag filters.
- Add `src/exporter.py` with UTF-8, properly escaped CSV output and tags included.
- Add task tags: multiple tags per task, add/remove tags, filter by tag, tags shown in listings.
- Add `task_tags` table with automatic, non-destructive migration for existing databases.
- Add `tag add`, `tag remove` and `tag list` CLI commands, plus `--tags` on `add` and `--tag` on `list`.
- Fix outdated `test_task_completion` test (used a method that does not exist).
